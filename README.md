# Bandeja

Mi app personal de productividad: GTD (captura, procesado, próximas acciones, proyectos, rutinas, revisión semanal) y hábitos con rachas de 90 días.

- Funciona en el navegador y se instala en el iPhone (Safari → Compartir → Añadir a pantalla de inicio).
- La sincronización entre dispositivos va por Supabase: los datos de `config.js` y la tabla de `setup.sql`.
